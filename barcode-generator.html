EAN-13 Barcode Generator — Instant Product Codes

This free URL encoder and decoder percent-encodes text, query strings and whole URLs in your browser. It supports component encoding (for a single query value), whole-URL encoding (keeps ://, ?, & intact and encodes only what needs escaping), and a strict RFC 3986 mode. Decoding handles malformed input gracefully. No data is ever sent to a server.

EAN-13 in 30 Seconds

Type or paste the product code (only digits matter). Hit Render and the barcode appears instantly with the exact EAN-13 module structure: start/end guards, center guard and the weighted check digit. If you enter 12 digits, the missing 13th is computed for you. Every code renders to exactly 95 modules, so the barcode scans correctly with standard readers.

Print-Ready Output

The barcode renders large and crisp on a white background. Download it as PNG for labels, drop it into invoices, or print directly. No registration, no watermark, no limits.

EAN-13 FAQ

What is the check digit? The 13th digit is computed with the 1-3-1-3 weighting algorithm and validates the rest of the code. Can I use this for real products? It generates correct EAN-13 geometry — actual product numbers for retail use must come from GS1 memberships and your supplier, so treat this as a label/print/development tool. Why 12 digits? EAN-13 is a 12-digit payload with a 13th computed check digit; enter either form and the tool normalizes it.
