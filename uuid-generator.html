UUID Generator — v4 & v7 in One Click

This free URL encoder and decoder percent-encodes text, query strings and whole URLs in your browser. It supports component encoding (for a single query value), whole-URL encoding (keeps ://, ?, & intact and encodes only what needs escaping), and a strict RFC 3986 mode. Decoding handles malformed input gracefully. No data is ever sent to a server.

Why v7 Is Useful

UUID v4 is the classic random ID: 122 bits of entropy, perfect for keys and identifiers where unpredictability matters. v7 encodes a millisecond timestamp into the first 48 bits, so IDs sort chronologically — ideal for database primary keys, event logs and pagination by createdAt, because new rows naturally follow old ones without an index penalty.

Bulk Generation   ·   Copy-Ready

Pick a count (1 to 100), generate, and every ID appears line by line ready to paste into code, SQL or spreadsheets. Prefer v7 for databases and v4 for tokens and API keys. Both versions are validated against the RFC shape every time.

UUID Generator FAQ

Which version should I use? v4 for random tokens, API keys and anything that must be unpredictable; v7 for rows that should sort by creation time (Postgres, MySQL, Mongo all store them fine as strings). Can it run offline? Yes — all generation uses the browser's crypto API, with a Math.random fallback; no network is involved. Are the IDs unique? v4 uses 122 bits of randomness; v7 combines a timestamp with random bits, so collisions are astronomically unlikely for normal workloads.
