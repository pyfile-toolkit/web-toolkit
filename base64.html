What is Base64?

Base64 is an encoding scheme that converts binary data into ASCII text using 64 characters. It is used to safely transmit binary data (images, files, audio) through text-based protocols like email and JSON APIs.

How to use the Base64 encoder/decoder

Type or paste text and click Encode to convert it to Base64, or paste Base64 and click Decode to get the original text. Everything happens locally in your browser — no data is uploaded.

Common Base64 uses

Base64 is common for embedding images in HTML/CSS, encoding authentication tokens in HTTP headers, and transferring binary attachments. Understanding encode/decode is essential for many developers and sysadmins.

Base64 FAQ

Is Base64 encryption? No, it is encoding, not encryption — it can be reversed instantly. Does Base64 reduce size? It increases size by about 33%. Is my data safe? Yes, everything runs locally.
