# SPEC — web-toolkit: SEO-подъём + редизайн/UX

Дата: 2026-09-22. Проект: `projects/web-toolkit` (live: pyfile-toolkit.github.io/web-toolkit, 62 HTML).

## Цель (1-2 предложения)

Поднять 7 страниц из позиций 68-82 в топ-20 Google и поднять engagement (0.29 → ≥0.45), чтобы существующий трафик (4550 показов/мес) конвертировался в клики и в `cta_llm_api_click`.

## Не-цели

- НЕ менять логику инструментов (`scripts/*-lib.js`) — тесты должны остаться зелёными.
- НЕ добавлять фреймворки/сборку. Всё статично.
- НЕ тратить деньги (никаких платных сервисов).
- НЕ переписывать все 62 страницы вручную — только shared-слой + точечные правки топ-страниц.
- НЕ обещать рост трафика мгновенно: SEO-эффект 2-4 недели.

## Критерии успеха (каждый с проверкой)

1. Общий design-system CSS подключён ко всем страницам.
   Проверка: `grep -L "styles.css" *.html guides/*.html | wc -l` → 0.
2. Единая шапка (лого + навигация + поиск) и подвал на каждой странице.
   Проверка: открыть 3 разные страницы, шапка/подвал идентичны.
3. Единая палитра и типографика (нет #0b0f1a vs #0f172a разнобоя).
   Проверка: визуально + `grep -c "0f172a\|0b0f1a"` не в styles.css → 0.
4. 7 топ-страниц: усилены title/description/H1/FAQ/внутренние ссылки.
   Проверка: `node scripts/test-*.js` зелёные; GSC через 2-4 недели поз < 20.
5. CTA на LLM API заметен и кликабелен на каждой странице (событие `cta_llm_api_click`).
   Проверка: GA4 Realtime ловит событие.
6. Мобильная вёрстка без горизонтального скролла (375px).
   Проверка: скриншот 375px.
7. Тесты проекта остаются зелёными.
   Проверка: прогнать все `scripts/test-*.js` → все PASS.

4. **Топ-страницы:** title/description/H1 под точный интент запроса, FAQ блок, 3-5 внутренних ссылок на смежные инструменты. Артефакт: диффы, IndexNow-пинг.
5. **CTA LLM API** — единый блок в шапке/футере + заметный блок в контенте. Артефакт: событие в GA4.
6. **Проверка:** тесты, 375px скриншот, push, IndexNow. Артефакт: отчёт в JOURNAL.

## Риски и откат

- **Риск:** поломка 62 страниц мигратором. **Откат:** git (все правки в одном коммите, revert).
