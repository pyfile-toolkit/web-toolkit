# Analytics Setup — Required for Tracking

## Google Analytics 4
1. Go to https://analytics.google.com
2. Create account → Property → Web
3. Get Measurement ID (G-XXXXXXXXXX)
4. Replace in index.html

## Google Search Console
1. Go to https://search.google.com/search-console
2. Add property: https://pyfile-toolkit.github.io/web-toolkit/
3. Choose "HTML tag" verification
4. Add the meta tag to index.html
5. Submit sitemap: https://pyfile-toolkit.github.io/web-toolkit/sitemap.xml

## What we'll see after setup:
- Organic search queries
- Click-through rates
- Top pages
- Countries
- Devices
